# GoBale Interactive Documentation Portal

پرتال تعاملی و جامع مستندات فریم‌ورک **GoBale** برای توسعه ربات‌های پیام‌رسان بله با زبان Go.

## ویژگی‌ها:
- **۱۷ فصل کامل و جامع:** پوشش ۱۰۰ درصدی تمام قابلیت‌ها، معماری، روتر، کانتکست، مدیا، کیبوردها، امنیت، FSM، دیتابیس WAL، وب‌سوکت، پرداخت و سامانه سفیر.
- **موتور جستجوی عمیق متن (Full-Text Search):** ایندکس‌گذاری و جستجوی بلادرنگ در تمام متون، پاراگراف‌ها و کدهای نمونه با کلید میانبر Ctrl+K.
- **طراحی مدرن تاریک (Dark Glassmorphic UI):** هدرهای کد سبک Mac، دکمه‌های کپی، هایلایت خودکار اسکرول (ScrollSpy) و لی‌اوت تک‌سایدبار ریسپانسیو.
- **آیکون‌های وکتور SVG / Lucide:** بدون استفاده از هرگونه اموجی طبق استانداردهای حرفه‌ای مستندات فنی.

## نحوه مشاهده:
کافی است فایل index.html را در هر مرورگری باز کنید.
