# مستندات جامع فریم‌ورک GoBale

پورتال رسمی و کامل مستندات فنی، معماری و رفرنس API فریم‌ورک **GoBale** (کتابخانه توسعه ربات‌های پیام‌رسان بله در زبان Go).

## مشاهده داکیومنت تحت وب
برای مشاهده نسخه وب تعاملی و کامل، فایل `index.html` موجود در همین پوشه را در مرورگر خود باز کنید:
```bash
open documentation/index.html
# یا در لینوکس:
xdg-open documentation/index.html
```

## ساختار فصل‌های داکیومنت
- **فصل ۱**: مقدمه، فلسفه طراحی و راهنمای شروع سریع (Quick Start)
- **فصل ۲**: معماری هسته و روش‌های اجرا (Long Polling, Webhook, WebSocket)
- **فصل ۳**: موتور مسیریابی و هندلرها (Router, Command Args, Filters)
- **فصل ۴**: موتور کانتکست (Context Engine - Ctx)
- **فصل ۵**: سیستم پیشرفته ارسال پیام، مدیا و آلبوم‌ها (Sending & Media Engine)
- **فصل ۶**: کیبوردها، منوهای درختی و صفحه‌بندی (Keyboards, Dynamic Menus & Pagination)
- **فصل ۷**: امنیت، محافظت گروه، میدلورها و AntiCrash (Zalgo Defense, AntiSpam, AntiLink)
- **فصل ۸**: موتور اخطار و مجازات پلکانی (Warning & Punishment Engine)
- **فصل ۹**: جریان‌های مکالمه‌ای و ویزاردها (Conversational Flows & FSM)
- **فصل ۱۰**: دیتابیس Write-Ahead Log (WAL) و مدیریت سشن‌ها
- **فصل ۱۱**: مدیریت چت‌ها و اختیارات گروه (Chat Administration)
- **فصل ۱۲**: موتور وب‌سوکت و انتقال پیشرفته فایل (WebSocket & File Transfer)
- **فصل ۱۳**: پرداخت‌ها، فروشگاه و سامانه سفیر (Payments & Safir Enterprise)
- **فصل ۱۴**: ایونت‌باس، لاگر ساختاریافته و داشبورد مانیتورینگ زنده
- **فصل ۱۵**: آنالیتیکس و جدول لیدربورد کاربران فعال
- **فصل ۱۶**: ابزارها، تقویم جلالی و هلپرهای عمومی
- **فصل ۱۷**: مرجع کامل API و توابع (Complete API Reference)
